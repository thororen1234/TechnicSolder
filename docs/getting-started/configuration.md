# Configuration Reference

!!! info "Docker users"
    Most of these are pre-configured in `compose.yml`. You only need to override values that differ from the defaults.

## Application

| Variable | Default | Description |
|----------|---------|-------------|
| `APP_NAME` | `Technic Solder` | Application name shown in the UI |
| `APP_ENV` | `production` | Environment (`production`, `local`) |
| `APP_KEY` | (generated) | Encryption key -- generated by `pnpm solder key:generate`. Keep it when moving or upgrading: it decrypts two-factor secrets. |
| `APP_DEBUG` | `false` | Enable debug mode (never in production) |
| `APP_URL` | `http://localhost` | Full URL where Solder is accessible |
| `APP_TIMEZONE` | `UTC` | Application timezone (also used for scheduled task times) |
| `PORT` | `3000` | Port the web server listens on |

## Database

| Variable | Default | Description |
|----------|---------|-------------|
| `DB_CONNECTION` | `mysql` | Database driver (`mysql`, `mariadb`, `pgsql`, or `sqlite`) |
| `DB_HOST` | `127.0.0.1` | Database host (use `mysql` in Docker) |
| `DB_PORT` | `3306` | Database port (`5432` by default for `pgsql`) |
| `DB_DATABASE` | `solder` | Database name. For `sqlite`, the path to the database file, relative to the Solder directory. |
| `DB_USERNAME` | `root` | Database user |
| `DB_PASSWORD` | (empty) | Database password |
| `DB_URL` | (empty) | Connection URL for MySQL/MariaDB or PostgreSQL; overrides the separate settings above when set |

## Cache & Session

| Variable | Default | Description |
|----------|---------|-------------|
| `CACHE_STORE` | `redis` | Cache driver. `redis`, or any other value (e.g. `file`) to keep the cache in memory. Docker uses `redis`. |
| `SESSION_DRIVER` | `redis` | Session driver. `redis`, or any other value (e.g. `file`) to keep sessions in memory, which logs everyone out when Solder restarts. Docker uses `redis`. |
| `SESSION_LIFETIME` | `120` | Session lifetime in minutes |
| `SESSION_COOKIE` | `solder_session` | Session cookie name |
| `SESSION_SECURE_COOKIE` | `false` | Only send the session cookie over HTTPS |
| `REDIS_HOST` | `127.0.0.1` | Redis/Valkey host (use `redis` in Docker) |
| `REDIS_PASSWORD` | (empty) | Redis/Valkey password (not needed for Docker default) |
| `REDIS_PORT` | `6379` | Redis/Valkey port |

## Mail

| Variable | Default | Description |
|----------|---------|-------------|
| `MAIL_ENABLED` | `false` | Set to `true` to enable password reset via email |
| `MAIL_MAILER` | `smtp` | Mail driver (`smtp`, or `log`/`array` to not send mail) |
| `MAIL_HOST` | (empty) | SMTP server host |
| `MAIL_PORT` | `587` | SMTP server port |
| `MAIL_USERNAME` | (empty) | SMTP username |
| `MAIL_PASSWORD` | (empty) | SMTP password |
| `MAIL_SCHEME` | (unset) | Optional SMTP scheme override: `smtp` for SMTP with automatic STARTTLS when supported, or `smtps` for implicit TLS. When unset, empty, or null, Solder uses `smtps` on port 465 and `smtp` otherwise, including in Docker. |
| `MAIL_FROM_ADDRESS` | (empty) | Sender email address |
| `MAIL_FROM_NAME` | `Technic Solder` | Sender name |

No `.env` migration is required for an existing working mail configuration. `MAIL_ENCRYPTION` is unused and may be removed as optional cleanup. Set `MAIL_SCHEME` only to override automatic selection; its accepted values are `smtp` and `smtps`, not `tls` or `ssl`.

## Solder

| Variable | Default | Description |
|----------|---------|-------------|
| `SOLDER_REPO_LOCATION` | `/var/www/mods.example.com/` | Path or URL to the mod repository. Trailing slash added automatically if omitted. |
| `SOLDER_MIRROR_URL` | `http://mods.example.com/` | Public URL the launcher uses to download mod files. Trailing slash added automatically if omitted. |
| `SOLDER_MD5_CONNECT_TIMEOUT` | `5` | Seconds to wait when connecting for MD5 checksums |
| `SOLDER_MD5_FILE_TIMEOUT` | `30` | Seconds to wait when computing MD5 checksums |
| `SOLDER_DISABLE_MOD_API` | `false` | Set to `true` to disable public `/api/mod` reads; authorized manager bearer tokens retain access |
| `SOLDER_CORS_ORIGINS` | `*` | Allowed CORS origins (comma-separated or `*` for all) |
| `SOLDER_ADVANCED_MODE` | `false` | Set to `true` to show Mojang Java runtime overrides in build creation, editing, and details. UI only: API access and saved overrides are unaffected. |
| `SOLDER_INITIAL_ADMIN_EMAIL` | `admin@example.com` | Email of the admin user created by `pnpm solder setup --no-interaction` |
| `SOLDER_INITIAL_ADMIN_PASSWORD` | (generated) | Password of that admin user; a random one is printed to the console if not set |
| `SOLDER_SCHEDULED_UPDATE_CHECKS` | `true` | Check every modpack's latest build for mod updates each night at 04:00 (needs `pnpm scheduler` running) |
| `SOLDER_DISCORD_WEBHOOK` | (empty) | Post update checks, finished imports, published builds and repository problems to this Discord webhook |
| `SOLDER_DISCORD_BOT_TOKEN` | (empty) | Send those notifications as direct messages from this Discord bot instead |
| `SOLDER_DISCORD_USER_ID` | (empty) | Discord user IDs (comma-separated) the bot sends direct messages to |
| `CURSEFORGE_API_KEY` | (empty) | Required to import mods and modpacks from CurseForge |

??? note "Advanced Configuration"

    **Queue**

    | Variable | Default | Description |
    |----------|---------|-------------|
    | `QUEUE_CONNECTION` | `sync` | `sync` runs imports, exports and update checks inside the web request; `redis` runs them in the worker (`pnpm worker`). Docker uses `redis`. |

    **API tokens**

    | Variable | Default | Description |
    |----------|---------|-------------|
    | `SANCTUM_TOKEN_EXPIRATION` | (empty) | Minutes until API tokens expire; empty for never |
    | `SANCTUM_TOKEN_PREFIX` | `sldr_` | Prefix added to new API tokens |

    **Application (rarely changed)**

    | Variable | Default | Description |
    |----------|---------|-------------|
    | `BCRYPT_ROUNDS` | `12` | Bcrypt hashing rounds |
    | `SOLDER_STORAGE_PATH` | `storage/app/private` | Where waiting imports and finished exports are stored, relative to the Solder directory |
    | `SOLDER_CHECK_COMPROMISED_PASSWORDS` | `true` | Check new passwords against the Have I Been Pwned database |

    Logs are written to `storage/logs/solder.log` and to the console.
